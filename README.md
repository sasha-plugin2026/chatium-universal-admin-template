# Универсальный администратор — шаблон Chatium

ИИ-администратор принимает заявки клиентов вместо менеджера: ведёт диалог в чате, собирает услугу
с уточнением, проверяет свободное время по расписанию салона, называет цены только из прайса,
сохраняет заявку и уведомляет сотрудников. Для сотрудников — список заявок со статусами,
настройки салона и напоминание позвонить клиенту накануне визита.

Демо: <ссылка на демо-аккаунт — заполнить при публикации>

## Что внутри

```
zayavki/                 воркспейс «Заявки» — всё приложение целиком
  index.tsx              страница клиента «Оставить заявку» + токен для чата с агентом
  leads.tsx              страница «Заявки» (только роль Staff+)
  settings.tsx           страница «Настройки салона» (только роль Staff+)
  main.agent.json        ИИ-агент и его инструменты
  api/                   JSON-роуты: заявки, прайс, настройки
  server/                слоты и расписание, прайс, настройки, уведомления, напоминания
  tables/                таблицы Heap: заявки, прайс, настройки салона
  tools/                 инструменты агента; registry.ts регистрирует их плагинным хуком
  jobs/                  задача напоминания о завтрашнем визите
pages/index.tsx          необязательный редирект корня аккаунта на страницу чата
```

## Как поставить

1. Скопируйте папку `zayavki/` в корень аккаунта Chatium (Source Git или синхронизация).
   Папка самодостаточна: своих корневых модулей у неё нет, таблицы создаются при первом обращении.
2. Откройте `/<домен>/zayavki` — это страница клиента, вход не нужен.
3. Войдите сотрудником (роль Staff или выше) и откройте `/zayavki/settings`: заполните название салона,
   рабочие часы, выходные, длительность окна, час напоминания и прайс услуг. Пока название не заполнено,
   помощник представляется нейтрально — «наш салон».
4. Сотрудникам доступна `/zayavki/leads` — список заявок и смена статуса.
5. Чтобы сразу увидеть шаблон в работе, откройте «Настройки салона» → блок «Демо-данные» →
   **«Наполнить демо-данными»**: появится прайс из восьми услуг и три заявки в разных статусах,
   с которыми уже можно поговорить с помощником. Кнопка «Убрать демо-данные» очищает таблицы.

Чтобы корень аккаунта сразу открывал чат, скопируйте `pages/index.tsx` (он редиректит `/` на страницу
чата). Если в аккаунте уже есть своя корневая страница, добавлять его не нужно.

## Что нужно аккаунту

- модуль ИИ-агентов и настроенная модель — без неё чат не ответит, а страница заявок и настройки
  продолжат работать;
- уведомления сотрудникам идут через Store (`sendNotification`) и попадают в Inbox;
  пока раздел Inbox не раскатан в аккаунте, сотрудники увидят уведомление только в API/логах;
- напоминание о визите ставится задачей на завтра, поэтому аккаунту нужны jobs (есть в тарифе).

## Ограничения

- агент и его инструкции рассчитаны на салоны красоты: список уточняющих вопросов (маникюр, стрижка,
  педикюр, брови, окрашивание) задан в `zayavki/main.agent.json`, его можно переписать под свою нишу;
- в тексты уведомлений телефон клиента не попадает: он виден сотруднику на странице заявок.

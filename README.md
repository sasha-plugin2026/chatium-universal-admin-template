# Универсальный администратор — шаблон Chatium

ИИ-администратор принимает заявки клиентов вместо менеджера и подходит любой компании, которая
работает по записи и прайсу: салону и студии, клинике, сервису, школе, тренеру, мастеру-частнику.
Агент ведёт диалог в чате, уточняет услугу, называет цены только из прайса, проверяет свободное
время по рабочим часам и выходным, сохраняет заявку и уведомляет сотрудников. Для сотрудников —
список заявок со статусами, настройки записи и напоминание позвонить клиенту накануне визита.

Отрасль в коде не зашита: название компании, логотип, рабочие часы, выходные, длительность окна,
час напоминания и прайс задаются в настройках, а не в коде.

## Что внутри

```
zayavki/                 воркспейс «Заявки» — всё приложение целиком
  index.tsx              страница клиента «Оставить заявку» + токен для чата с агентом
  leads.tsx              страница «Заявки» (только роль Staff+)
  settings.tsx           страница «Настройки записи» (только роль Staff+)
  main.agent.json        ИИ-агент и его инструменты
  api/                   JSON-роуты: заявки, прайс, настройки
  server/                слоты и расписание, прайс, настройки, уведомления, напоминания
  tables/                таблицы Heap: заявки, прайс, настройки записи
  tools/                 инструменты агента; registry.ts регистрирует их плагинным хуком
  jobs/                  задача напоминания о завтрашнем визите
index.tsx                корневая страница аккаунта: редирект `/` на страницу чата
```

## Как поставить

1. Скопируйте папку `zayavki/` в корень аккаунта Chatium (Source Git или синхронизация).
   Папка самодостаточна: своих корневых модулей у неё нет, таблицы создаются при первом обращении.
2. Откройте `/<домен>/zayavki` — это страница клиента, вход не нужен.
3. Войдите сотрудником (роль Staff или выше) и откройте `/zayavki/settings`: заполните название компании,
   рабочие часы, выходные, длительность окна, час напоминания и прайс услуг. Пока название не заполнено,
   помощник представляется нейтрально — «наша компания».
4. Сотрудникам доступна `/zayavki/leads` — список заявок и смена статуса.
5. Чтобы сразу увидеть шаблон в работе, откройте «Настройки записи» → блок «Демо-данные» →
   **«Наполнить демо-данными»**: появится прайс из восьми услуг и три заявки в разных статусах,
   с которыми уже можно поговорить с помощником. Кнопка «Убрать демо-данные» очищает таблицы.

Чтобы корень аккаунта сразу открывал чат, скопируйте `index.tsx` в **корень** аккаунта: путь роута в
Chatium равен пути файла от корня репозитория, поэтому корневая страница должна лежать именно в корне
(`pages/index.tsx` обслуживал бы адрес `/pages`). Если в аккаунте уже есть своя корневая страница,
добавлять его не нужно — в своём аккаунте оставьте свой редирект.

## Что нужно аккаунту

- модуль ИИ-агентов и настроенная модель — без неё чат не ответит, а страница заявок и настройки
  продолжат работать;
- уведомления сотрудникам идут через Store (`sendNotification`) и попадают в Inbox;
  пока раздел Inbox не раскатан в аккаунте, сотрудники увидят уведомление только в API/логах;
- напоминание о визите ставится задачей на завтра, поэтому аккаунту нужны jobs (есть в тарифе).

## Ограничения

- демо-данные — пример сервисной компании (восемь услуг и три заявки в разных статусах); кнопка
  «Убрать демо-данные» очищает таблицы, после чего прайс заполняется под вашу нишу;
- уточняющие вопросы агент задаёт по прайсу: если в прайсе есть несколько похожих услуг, он спросит,
  какая нужна. Своего списка вопросов под конкретную нишу в коде нет — при необходимости он
  дописывается в `zayavki/main.agent.json`;
- в тексты уведомлений телефон клиента не попадает: он виден сотруднику на странице заявок.
